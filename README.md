# 投经刷题

投资经济学刷题小程序（网页版），不背单词式一题一卡：点选项马上出对错和解析，做错的自动进错题本。

在线试用：https://muse.ai/s/tou-jing-shua-ti-xbr6xe7oi94xfxv/yDxb-bu1ywilduLxm7jQo_r6olrcMPFfgDSFpCVGUg0

## 题库

共 178 道题，来自《投资经济学》（任淮秀第五版）学习通作业，答案已按平台校准：

| 类型 | 数量 | 说明 |
| --- | --- | --- |
| 选择题 | 39 | 带完整 A–D 选项，点选判分 |
| 判断题 | 83 | 点「对 / 错」判分 |
| 自测卡 | 56 | 选项未完整记录，先想答案再点开看，自评会了 / 还不会 |

第六、八、十章的部分选择题在学习通上只记了题干和答案、没记全四个选项，所以做成了自测卡；第六章第 20–24 题题干未完整记录，只看答案和解析记概念。

另有 31 道标 ★ 的题，是作者第一次做时做错过的，可单独练。

## 用法

直接用浏览器打开 `index.html` 就能刷，不用装任何东西，不用联网。

- 顶部可按模式筛选：全部 / 错题 ★ / 选择题 / 判断题 / 自测卡
- 可按章节筛选，可打乱顺序
- 做错的题自动进错题本（存在浏览器本地），刷完一轮出正确率，可以只练错题

## 换成自己的题

题库在 `quiz-data.json`，每题一个对象：

```json
{
  "id": "ch5-2",
  "chapter": 5,
  "chapter_name": "投资体制",
  "num": 2,
  "type": "single",
  "stem": "下列说法错误的是：（ ）",
  "options": [
    { "key": "A", "text": "……" },
    { "key": "B", "text": "……" },
    { "key": "C", "text": "……" },
    { "key": "D", "text": "……" }
  ],
  "answer": "D",
  "answer_text": "投资资源的产权关系的基本功能是……",
  "was_wrong": true,
  "analysis": "解析……"
}
```

- `type`：`single` 选择题（需 4 个选项）、`judge` 判断题（`answer` 为 `对` / `错`）、`flash` 自测卡（无完整选项，`answer` + `answer_text` 为答案）
- `was_wrong` 为 `true` 时显示 ★ 标记，进「错题」模式
- 改完 `quiz-data.json` 后，用同样的题目数据重新生成 `index.html`（把 JSON 嵌进模板里 `__QUIZ_DATA__` 的位置）即可
